# 验证范围

当前插件版本：0.4.0；Agent：0.1.1。

## 已验证

- 原节点 DOM/路由保留、Plus 站内注入与还原、移动双菜单去重、详情链接幂等转换。
- 原后台导航与头部保留、后台会话使用、React 路由同步、已有机器选择与回填。
- 登录失效、权限拒绝、错误提示、表单失败保留、目标字段类型、未配置状态。
- SQLite 去重、冲突拒绝、待处理记录修复、任务租约、补测限流、解绑历史、磁盘保护和备份完整性。
- 首个不足一小时的数据段聚合，绑定时间范围之外的数据不被纳入。
- Laravel 真实 Router/Eloquent/权限中间件下的隔离集成；身份为测试 guard。
- Go race/vet、公网目标检查、TCP 成功/拒绝、上报重试、缓存清理、进程超时和结构化回程解析。
- 两种 Linux 架构交叉构建、插件包体积和所有发布资源校验。
- 默认前后台编译资源中的浏览器检查，以及两台测试节点的短时真实回传与补测。

## 限制

尚未完成48小时稳定性验收、100台真实并发或完整90天数据量的长期压力测试。顺序合成上报结果不能视为生产吞吐承诺。

免费来源、流媒体/AI 服务检测可能变化或误判。第三方主题、网络共享存储、多面板同时写同一SQLite目录不在当前支持范围。
